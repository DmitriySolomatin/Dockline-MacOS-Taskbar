# Dockline для macOS

Панель задач для Mac: открытые окна перед глазами, быстрое переключение и порядок на рабочем столе.

[Сайт](https://getdockline.app/ru/) · [English](README.md)

## Обратная связь

- **Что-то не работает?** [Сообщите об ошибке](https://github.com/DmitriySolomatin/Dockline-MacOS-Taskbar/issues/new/choose).
- **Есть идея?** [Предложите улучшение](https://github.com/DmitriySolomatin/Dockline-MacOS-Taskbar/discussions/categories/ideas).
- **Нужна помощь с приложением?** [Задайте вопрос](https://github.com/DmitriySolomatin/Dockline-MacOS-Taskbar/discussions/categories/q-a).

Можно писать по-русски и по-английски. Сначала проверьте, нет ли уже похожей темы. Если есть — дополните её.

## Не публикуйте личные данные

Сообщения здесь видны всем. Уберите из снимков и логов email, ключи лицензий, данные платежей, личные названия окон и пути к файлам.

По вопросам покупок, доступа к аккаунту и безопасности пишите на [help@getdockline.app](mailto:help@getdockline.app). Никому не сообщайте пароли и коды входа.

Этот репозиторий — для обратной связи. Исходный код Dockline здесь не публикуется.
