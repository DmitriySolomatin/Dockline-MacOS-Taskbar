# Dockline for macOS

A taskbar for your Mac: see open windows, switch between tasks, and keep your workspace organised.

[Website](https://getdockline.app/) · [Русский](README.ru.md)

## Feedback

- **Something is broken?** [Report a bug](https://github.com/DmitriySolomatin/Dockline-MacOS-Taskbar/issues/new/choose).
- **Have an idea?** [Suggest an improvement](https://github.com/DmitriySolomatin/Dockline-MacOS-Taskbar/discussions/categories/ideas).
- **Need help using Dockline?** [Ask a question](https://github.com/DmitriySolomatin/Dockline-MacOS-Taskbar/discussions/categories/q-a).

English and Russian are welcome. Please search existing reports first. Add to a matching discussion instead of opening a duplicate.

## Keep private information private

Everything posted here is public. Remove email addresses, license keys, payment details, personal window titles, and private file paths from screenshots and logs.

For purchases, account access, or security concerns, email [help@getdockline.app](mailto:help@getdockline.app). Never post passwords or sign-in codes.

This repository is for community feedback. Dockline's application source code is not published here.
