Dockline gives individual Mac windows their own buttons along the bottom of your screen. Pick a document by title, preview a group of windows, and keep the right tasks visible across displays and Spaces.

**Try every feature free for one calendar month. No card required.**

## Find the window you meant

### Several windows. One familiar app.

Open a particular Finder folder, browser window or document directly from its title. Keep separate window buttons, or collapse an app's windows into a group always, when space is limited, or never. Tabs inside a browser window stay in the browser.

Optional previews help you recognize similar windows at a glance:

### A workspace across screens and Spaces.

Choose windows from **all displays or the current display**, and **all desktops or the current desktop**. Desktop buttons follow Mission Control order, including full-screen and Split View spaces. You can also switch desktops with the mouse wheel over the panel.

### A panel that fits your day.

Pin apps you return to, keep open windows readable, and adjust panel height, task widths, spacing and margins. Choose your theme and glass density, then use auto-hide when you want more room.

[Try the interactive demo](https://getdockline.app/#features) · [Explore the settings guide](https://getdockline.app/settings/)

The website demo uses example windows; its controls act only on the page. The settings guide explains the actual app controls and their conditions.

## Install and get started

1. **[Download Dockline for macOS](https://github.com/DmitriySolomatin/Dockline-MacOS-Taskbar/releases/latest)**, open the **DMG** and drag **Dockline.app** to **Applications**.
2. Open Dockline from Applications and complete setup. Trial starts automatically when Dockline connects.
3. Allow **Accessibility** to list and control windows. If you turn on **Window previews**, allow the separate **Screen Recording** permission.
4. Open two ordinary windows in an app, then select each by its title on the panel. Try the grouping choices in **Settings → Windows and groups**.

Supports **macOS 26.5 or later, on Apple silicon and Intel**. The installer is signed with Developer ID and notarized by Apple.

Need a hand? Follow the [installation and first-open guide](https://getdockline.app/support/#installation), [opening troubleshooting](https://getdockline.app/support/#opening-blocked), [panel visibility guide](https://getdockline.app/support/#panel-not-visible) or [launch at login guide](https://getdockline.app/support/#launch-at-login).

Use the **DMG** to install the app. GitHub's “Source code” archives contain only this repository's community files.

## Permissions and compatibility

- **Accessibility** reads window titles and lets Dockline activate, minimize or close windows.
- **Screen Recording** is optional, for window previews. Titles remain usable with previews off.
- **Automation** is separate for each supported player and is needed for track-position features.

Read the [permissions reference](https://getdockline.app/settings/#permissions) for details.

Dragging windows between displays and desktops is an **opt-in beta**. The two switches start off, and compatibility is still being tested. Window buttons, filters and desktop switching work independently of these transfers.
