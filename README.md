# Dockline — a window taskbar for macOS

Dockline puts individual Mac windows in a bar along the bottom of your screen. Read their titles, preview windows in a group, and select the document or browser window you need. With several displays or Spaces, choose which windows each panel shows and switch desktops from the bar.

**macOS 26.5 or later · Apple silicon and Intel · One calendar month free · No card required**

## Find the window you meant

Several Finder folders, two browser windows and a few documents can share only a handful of app icons. Dockline gives those windows named buttons so you can select one directly. A browser window is one task; tabs inside it stay in the browser.

| What you want to do | How Dockline helps |
| --- | --- |
| Choose a particular window of the same app | Individual window buttons show titles. Windows can share a background and app icon while keeping separate buttons. |
| Keep a busy panel readable | Collapse an app's windows into one button always, when space is limited, or never. A group list lets you choose a window by title. |
| Recognize similar windows | Optional previews add images to the group list. They require Screen Recording permission. |
| Organize more than one screen | Show windows from all displays or the current display, and from all desktops or the current desktop. |
| Move between Spaces | Desktop buttons follow Mission Control order and include full-screen and Split View spaces. Optional mouse-wheel switching works over the panel. |
| Make room for the way you work | Adjust panel height, task widths, spacing, margins, theme, glass density and auto-hide. |

See these choices in the [website demo](https://getdockline.app/#features). The demo uses example windows; its controls act only on the page. The [settings guide](https://getdockline.app/settings/) explains the actual app controls and their conditions.

## Install and get started

The public installer supports **Apple silicon and Intel Macs running macOS 26.5 or later**. It is signed with Developer ID and notarized by Apple.

1. [Download Dockline](https://getdockline.app/), open the DMG and drag **Dockline.app** to **Applications**.
2. Open Dockline from Applications and complete setup.
3. Allow **Accessibility** when you want Dockline to list and control windows. Turn on **Window previews** if you also want images in group lists; this asks for separate Screen Recording permission.
4. Open two ordinary windows in an app you use, then select each by its title on the panel. Use **Settings → Windows and groups** to try the grouping choices.

Trial starts automatically after setup when Dockline connects. All features are included for one calendar month. For a permission that has not taken effect, follow the [step-by-step guide](guides/window-previews-and-permissions.md).

## Permissions and compatibility

**Accessibility** lets Dockline read window titles and activate, minimize or close windows. **Screen Recording** is optional and supplies window previews; titles remain usable with previews off. Track-position features need separate Automation permission for each supported player. See the [permissions reference](https://getdockline.app/settings/#permissions).

Dragging windows between displays and desktops is an **opt-in beta**, with separate switches that start off. Compatibility is still being tested. You can use window buttons, filters and desktop switching independently of those transfers.

Dockline has 15 interface languages: English, Brazilian Portuguese, Turkish, Russian, Spanish, Slovak, German, French, Italian, Japanese, Korean, Ukrainian, Simplified Chinese, Traditional Chinese for Taiwan, and Traditional Chinese for Hong Kong.
