# Dockline — a window taskbar for macOS

Dockline is a native macOS taskbar for individual windows. Find a window by its title, preview its contents, and switch between windows and Spaces from the same bar.

[Download Dockline](https://getdockline.app/) · [Settings guide](https://getdockline.app/settings/) · [Changelog](https://getdockline.app/updates/) · [Help](https://getdockline.app/support/)

## What you can do

- See open windows with their app icons and titles, and group windows from the same app.
- Preview a window before switching to it.
- Switch between Spaces and choose which windows appear on each display.
- Adjust the panel's position, size, appearance, grouping, and hiding behavior.
- Use Dockline in 15 interface languages.

The [interactive website](https://getdockline.app/#features) shows the panel in action. The [settings guide](https://getdockline.app/settings/) explains each control and its limits, including optional beta features.

## Install and try

Dockline requires **macOS 26.5 or later** and supports **Apple silicon and Intel Macs**. The current installer is signed with Developer ID and notarized by Apple.

1. [Download the DMG](https://getdockline.app/) and move Dockline to Applications.
2. Open Dockline and follow the setup steps for macOS permissions.
3. Start your trial. It lasts one calendar month and does not require a payment card.

A purchase provides one year of access on two Macs, with no automatic renewal. See [current pricing and the remaining-trial discount](https://getdockline.app/#pricing).

For installation, permissions, or restoring a purchase, start with the [support guide](https://getdockline.app/support/). [Release notes](https://getdockline.app/updates/) explain what changed in each version.
